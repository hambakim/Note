# 로또 1등 그 후

"로또 되면 바닷가에 별장 짓고, 최고급 컴퓨터랑 게임기 들여놓고, 마당에 동물 키워야지"를 실제로 해보는 10년 시뮬레이션 게임입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.

## 핸드폰 앱으로 설치하기 (PWA)

앱스토어 없이 홈 화면에 아이콘을 만들어 앱처럼 쓰는 방식입니다. 설치하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷이 없어도 플레이할 수 있습니다.

### 1단계: 인터넷 주소 만들기 (GitHub Pages, 무료, 한 번만)

1. GitHub에서 이 저장소를 열고 **Settings → Pages**로 들어갑니다.
2. **Source**를 `Deploy from a branch`로 두고, 브랜치를 이 게임이 있는 브랜치(병합 후에는 `main`)로, 폴더를 `/ (root)`로 고른 뒤 **Save**를 누릅니다.
3. 1~2분 뒤 아래 주소로 접속됩니다.
   `https://<GitHub 아이디>.github.io/<저장소 이름>/lotto-simulator/`

참고: 무료 계정은 공개(public) 저장소에서만 Pages를 쓸 수 있습니다.

### 2단계: 홈 화면에 추가

- **안드로이드(크롬)**: 위 주소 접속 → 오른쪽 위 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰(사파리)**: 위 주소 접속 → 아래쪽 공유 버튼 → **홈 화면에 추가**

### 앱 구성 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 본체 (폰 화면용 하단 고정 버튼, 상단 상태 바, 바텀 시트 팝업 포함) |
| `manifest.webmanifest` | 앱 이름, 아이콘, 전체 화면 실행 설정 |
| `sw.js` | 오프라인 캐시 (서비스 워커) |
| `icon.svg`, `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 진행 순서

1. **번호 고르기**: 1~45 중 6개를 고르고 추첨합니다. 무조건 1등에 당첨됩니다.
2. **당첨금 수령**: 실제 세율로 세금을 뗍니다. 3억 원까지는 22%, 넘는 부분은 33%입니다. 실제 확률(8,145,060분의 1)로 따지면 몇 장째에 당첨됐을지도 보여줍니다.
3. **버킷리스트 구매**
   - 바닷가 부지: 양양, 제주 애월, 남해, 여수
   - 별장 짓기: 모던 단층, 2층 통유리, 한옥, 컨테이너. 짓는 데 몇 개월이 걸립니다.
   - 게임룸: 게이밍 PC, PS5 Pro, 스위치 2, 레이싱 시뮬레이터, 오락실 기계 등
   - 마당 동물: 골든 리트리버, 웰시코기, 고양이, 알파카, 포니, 염소, 닭
   - 탈것, 인생 결정(퇴사, 부모님 집, 세계 일주, 기부), **내가 직접 추가한 꿈**
4. **시간 보내기**: 한 달 또는 1년씩 진행합니다. 매달 아래 항목이 계산됩니다.
   - 월급, 생활비, 유지비
   - 예금 이자: 연 3%, 이자소득세 15.4% 공제
   - 재산세: 7월과 9월
   - 무작위 사건: 태풍, 친척의 돈 부탁, 투자 사기 문자, 성수기 렌트 제안 등
5. **10년 결산**: 총자산, 평균 행복도, 월별 행복도 그래프, 분야별 지출을 보여줍니다.

## 행복도 계산 방식

- 물건이 주는 기쁨은 산 직후가 가장 크고, 시간이 지나면 줄어듭니다(쾌락 적응).
- 동물, 가족 선물, 기부는 기쁨이 오래 남습니다.
- 회사를 계속 다니면 스트레스가 있습니다. 반대로 퇴사했는데 할 일이 없으면 무료함 때문에 행복도가 떨어집니다.
- 동물이 너무 많은데 관리인이 없으면 돌봄 피로가 쌓입니다.
